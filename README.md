# 🌦️ Previsão do Tempo

Aplicação web desenvolvida com React para consultar informações
meteorológicas de várias cidades do Brasil e do mundo.

## Tecnologias
- React
- JavaScript
- CSS
- Vite
- Node.js
- Express

## Funcionalidades
- Consulta meteorológica por cidade.
- Exibição das informações do clima.
- Histórico de consultas.

## Como executar
1. Clone o repositório.
2. Execute npm install.
3. Execute npm run dev:all.
